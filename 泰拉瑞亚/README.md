# 泰拉瑞亚风格 2D 沙盒

单文件 HTML5 2D 沙盒游戏 demo，向《泰拉瑞亚》致敬。运行 `泰拉瑞亚.html` 即可游玩，无任何依赖、不需要构建。

## 运行

直接双击 `泰拉瑞亚.html` 用浏览器打开，或执行：

```bash
# 任意静态文件服务
python -m http.server
# 然后访问 http://localhost:8000/泰拉瑞亚.html
```

## 玩法

像素风 2D 沙盒，包含挖掘、建造、合成、战斗、探索、昼夜循环等核心要素。

- **挖掘**：左键挖掘方块，矿石掉落原料
- **放置**：右键放置方块/工具台/熔炉
- **合成**：`Tab` 打开背包与合成界面，按配方合成工具、武器、材料
- **战斗**：用工具/武器攻击敌人
- **探索**：程序随机生成世界，含草地、砂地、岩石、矿脉、雪原等多种生态与不同生物群系

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `空格` | 跳跃 |
| `A` / `D` | 左右移动 |
| `鼠标左键` | 挖掘 / 攻击 |
| `鼠标右键` | 放置方块 |
| `1`-`0` | 快捷栏选择 |
| `Tab` | 背包 / 合成 |
| `E` | 小地图 |
| `Esc` | 暂停 |

## 系统与内容

- **方块**：泥土、草块、石头、木材、树叶、沙、铜/铁/金矿石、雪、基岩、黏土、砂岩、水、火把、工作台、熔炉
- **工具/武器**：木质、石质、铁质镐与剑
- **合成**：工作台（铺板、火把、工作台、熔炉、基础工具）、熔炉（熔炼铜/铁/金锭）
- **世界**：程序化噪声地形、昼夜天气、多生态群系、地底矿脉

## 技术

- 纯原生 JavaScript + Canvas 2D，单 HTML 文件（约 1200 行）
- 无框架、无第三方库、无构建步骤
- 值噪声（fbm）程序生成地形与生态
- 像素渲染（`image-rendering: pixelated`）
