# H5 游戏合集

纯前端 HTML5 小游戏集合，所有游戏均为单文件实现，无依赖、无构建步骤，直接用浏览器打开即可游玩。

## 游戏列表

| 游戏 | 文件 | 说明 |
| --- | --- | --- |
| 🎱 台球 | `pool.html` | 2D 台球模拟游戏 |
| 🎁 盲盒 | `盲盒小游戏.html` | 盲盒抽取小游戏 |
| 🍦 雪糕 | `雪糕小游戏.html` | 雪糕主题休闲游戏 |
| 📝 单词 | `单词小游戏/index.html` | 单词学习小游戏 |
| ⛏️ 泰拉瑞亚 | `泰拉瑞亚/泰拉瑞亚.html` | 泰拉瑞亚风格 2D 沙盒游戏 |

## 运行方式

### 方法一：直接打开
双击任意 `.html` 文件，用浏览器打开即可。

### 方法二：本地服务器
```bash
# Python
python -m http.server

# Node.js
npx serve .

# 然后访问 http://localhost:端口号
```

## 技术栈

- 纯 HTML5 + Canvas 2D
- 原生 JavaScript，无框架依赖
- 单文件架构，便于部署和分享
