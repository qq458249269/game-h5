# 🎮 经典街机游戏厅 · H5 复刻合集

用**纯原生 HTML5 Canvas + Web Audio** 复刻的 21 款经典街机游戏。
零依赖、零构建、零外部资源 —— 每个游戏一个独立文件夹，双击 `index.html` 即可离线游玩。

从「游戏厅」入口页开始浏览：打开根目录的 **`index.html`**。

## 🎮 操作速查

| 类型 | 移动 | 跳/上 | 攻击 | 技能 |
|------|------|-------|------|------|
| 清版动作/平台 | ←→↑↓ | 空格 | Z | V/B/X（各游戏不同）|
| 格斗 | A/D | W | J/K | L / I（弹格）|
| 横版射击 | ←→ | — | Z | X 炸弹 |
| 纵版射击 | 方向键 | — | Z(可蓄力) | X 炸弹 |
| 益智 | ←→↓ | ↑ 旋转 | 空格 快落 | P 暂停 |

每款游戏页面底部都有各自的按键说明。手机浏览器会自动出现**触屏按钮**。

## ✨ 实现要点

- **纯 Canvas 2D 逐帧绘制**，像素风角色/场景全部由代码绘制，无任何图片资源
- **Web Audio 合成音效**（振荡器 beep），无音频文件
- 每个文件即完整游戏：状态机、碰撞、AI、摄像机、关卡波次都在单个 `index.html` 里
- 最高分本地保存（部分游戏，localStorage）
- 特色系统还原：搓招输入缓冲（街霸）、怒气一闪（侍魂）、弹格（月华）、三段蓄力（1945）、
  被俘战机营救（小蜜蜂）、怒气爆气+魔法天书（三国战纪）、能量拳波（名将）等

## ▶️ 运行

任何现代浏览器直接打开 `index.html` 即可；推荐先用游戏厅入口页选游戏。
无需服务器、无需安装。
